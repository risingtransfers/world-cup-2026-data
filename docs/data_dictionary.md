# Data dictionary · world-cup-2026-data

Generated by Rising Transfers. Describes only the files in this repository.

## squads.csv

| Column | Description |
|---|---|
| player_id | RT internal player ID |
| player_name | Display name |
| slug | URL slug → `https://risingtransfers.com/en/players/{slug}/alternatives` |
| country | National team name |
| country_code | Three-letter code (e.g. ENG, BRA) |
| position | GK / DF / MF / FW |
| club | Current club |
| age | Age at export date |
| rt_value_estimate_eur | RT AI valuation (DNA form + league tier). **Not** third-party market value. |

## per90_stats.csv

| Column | Description |
|---|---|
| player_id, player_name, slug | Join keys to squads.csv |
| season | 2025-26 (current league seasons) |
| minutes | League minutes; rows with minutes < 450 excluded |
| goals_per90 … rating | Per-90 metrics from RT seasonal aggregates |
